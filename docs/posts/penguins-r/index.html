Exploring Palmer Penguins using R

An exploration of penguin body mass across species using R.
Author

Jiyuan Wang

Published

September 22, 2026

Data

Data: Palmer Penguins, Palmer Station Antarctica LTER.

Load the data

library(tidyverse)
library(palmerpenguins)

Average body mass by species

penguins |>
  drop_na(species, body_mass_g) |>
  group_by(species) |>
  summarise(
    mean_body_mass = mean(body_mass_g),
    n = n()
  )
# A tibble: 3 × 3
  species   mean_body_mass     n
  <fct>              <dbl> <int>
1 Adelie             3701.   151
2 Chinstrap          3733.    68
3 Gentoo             5076.   123

Gentoo penguins have the largest average body mass among the three species in this dataset.

Body mass distribution by species

penguins |>
  drop_na(species, body_mass_g) |>
  ggplot(aes(x = species, y = body_mass_g)) +
  geom_boxplot() +
  labs(
    x = "Species",
    y = "Body mass (g)",
    title = "Penguin Body Mass by Species"
  )

The boxplot shows that Gentoo penguins generally have a higher body mass than Adelie and Chinstrap penguins.

Flipper length and body mass

Next, I explored whether penguins with longer flippers also tend to have greater body mass.

penguins |>
  drop_na(flipper_length_mm, body_mass_g, species) |>
  ggplot(
    aes(
      x = flipper_length_mm,
      y = body_mass_g,
      color = species
    )
  ) +
  geom_point(alpha = 0.7) +
  labs(
    x = "Flipper length (mm)",
    y = "Body mass (g)",
    color = "Species",
    title = "Flipper Length vs Body Mass"
  )

The scatter plot shows a positive relationship between flipper length and body mass. Gentoo penguins tend to have both longer flippers and higher body mass than Adelie and Chinstrap penguins.

Average flipper length by species

I also calculated the average flipper length for each species.

penguins |>
  drop_na(species, flipper_length_mm) |>
  group_by(species) |>
  summarise(
    mean_flipper_length = mean(flipper_length_mm),
    median_flipper_length = median(flipper_length_mm),
    n = n()
  )
# A tibble: 3 × 4
  species   mean_flipper_length median_flipper_length     n
  <fct>                   <dbl>                 <dbl> <int>
1 Adelie                   190.                   190   151
2 Chinstrap                196.                   196    68
3 Gentoo                   217.                   216   123

Gentoo penguins have the largest average flipper length, while Adelie penguins generally have the shortest flippers.

Compare average flipper length

The differences in average flipper length can also be visualized with a bar chart.

penguins |>
  drop_na(species, flipper_length_mm) |>
  group_by(species) |>
  summarise(
    mean_flipper_length = mean(flipper_length_mm)
  ) |>
  ggplot(
    aes(
      x = species,
      y = mean_flipper_length,
      fill = species
    )
  ) +
  geom_col() +
  labs(
    x = "Species",
    y = "Average flipper length (mm)",
    title = "Average Flipper Length by Species"
  ) +
  guides(fill = "none")

The bar chart confirms that Gentoo penguins have noticeably longer flippers on average than the other two species.
